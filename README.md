# BigSmall Predictor SaaS

This application is the working SaaS copy. The original `index.html` remains untouched as the project reference.

## Run locally

1. Run `npm install`.
2. Copy `.env.example` to `.env` and set strong owner credentials.
3. Run `npm start`.
4. Open `http://localhost:3000`.

Set environment variables before using a real deployment.

Admin login is Owner/CEO only at `/admin`.
